# Properties

1. NPV is monotonic decreasing in rate
2. Clean price < dirty price
3. Modified duration < Macaulay duration
4. Duration is non-negative
5. Convexity is non-negative
6. Amortization ends at zero balance
7. Amortization principal+interest conserves payment
8. VaR is monotonic in confidence level
9. Sharpe is scale-invariant
10. Max drawdown is non-negative
11. FX round-trip: convert back yields original
12. Log returns preserve ordering
13. Rolling window length = N - window + 1
14. Payback period is within investment horizon
15. IRR of single positive cash flow is negative
16. Beta of asset with itself is 1
17. MIRR is between finance and reinvest rate
18. Sortino uses downside deviation
