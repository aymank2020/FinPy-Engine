# Architecture

FinPy-Engine follows a layered architecture:
- **core**: Base types and math
- **tvm**: Time-value-of-money
- **bonds**: Bond analytics
- **loans**: Loan amortization
- **risk**: Risk metrics
- **returns**: Return series analysis
- **fx**: Foreign exchange
- **schemas**: Serialization
- **migrations**: Schema versioning
- **cli**: Command-line interface
